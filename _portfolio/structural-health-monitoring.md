## Project Overview

Development of an integrated Structural Health Monitoring (SHM) system for high-mast lighting structures, focusing on structural vibration, dynamic behaviour and long-term condition monitoring.

## Objectives

- Develop a cost-effective and scalable SHM system for high-mast structures.
- Monitor structural vibration and dynamic responses under environmental loading.
- Investigate structural modal properties and identify potential changes in structural condition.
- Establish an IoT-based architecture for data acquisition, transmission, processing and visualisation.

## Technical Approach

- **Sensor systems:** Integration of MEMS accelerometers, gyroscopes and GNSS receivers.
- **Data acquisition:** High-frequency vibration measurement, embedded data processing and GNSS-based time synchronisation.
- **Communication:** Wireless data transmission using 4G and MQTT.
- **Cloud platform:** Remote data storage, processing and visualisation.
- **Structural analysis:** Operational Modal Analysis (OMA), modal identification and Finite Element Modelling (FEM).

## Key Contributions

- SHM system architecture and prototype development.
- Hardware integration and embedded data acquisition.
- Wireless communication and cloud-based monitoring infrastructure.
- Experimental validation using laboratory vibration testing.
- Modal identification and comparison with reference accelerometer measurements.

## Project Outcomes

Development and experimental evaluation of an integrated SHM prototype for high-mast lighting structures, providing a foundation for continuous structural monitoring and condition assessment.
